## [1.1.2] - 2026-09-06 (Tag: `v1.1.2`)

### Added
- **Native Mobile Application (`/mobile`)**:
  - Built with React Native & Expo SDK 57.
  - Native haptic feedback engine with `expo-haptics`.
  - Built-in Voice Audio Dispatch narration using `expo-speech`.
  - Native GPS location detection via `expo-location`.
  - Confetti cannon celebration using `react-native-confetti-cannon`.
  - Dedicated mobile app documentation and quick start guide in `mobile/README.md`.

---

## [1.1.1] - 2026-09-06 (Tag: `v1.1.1`)

### Added
- **Dawn Manifest Edition**:
  - Warm editorial ivory parchment aesthetic with Playfair Display typography and golden sunburst motifs.
  - 365-day deterministic identity manifesto rotation engine (`identityService.js`).
  - Curated 25+ James Clear reading catalog across 9 leverage categories with 90-day anti-repetition memory (`jamesClearCatalog.json`).
  - Midnight automatic rollover background monitor.
  - Navigation bar `[ 🔀 Randomize / Shuffle ]` button.
  - Motivational party popper confetti bursts on all step advancement buttons with harmonic web synthesizer audio chimes.
  - **Full Multi-Screen Responsiveness**:
    - Fixed glassmorphic bottom touch dock on Mobile (< 640px) and floating pill dock on Tablets (640px–1023px).
    - Compact responsive header with safe-area insets.
    - PWA web app manifest (`manifest.webmanifest`) and home-screen installability.
- **Automated Deployment**:
  - GitHub Pages CI/CD workflow in `.github/workflows/deploy.yml`.

---

## [1.0.0] - 2026-09-06 (Tag: `v1.0.0`)

### Added
- **Classic Obsidian Dark Edition**:
  - Obsidian slate dark mode with glassmorphism card architecture.
  - 4-phase sequential morning briefing workflow (Identity, Reading, Weather, Launch).
  - Open-Meteo zero-latency weather API integration with 12-hour forecast strip.
  - Gemini AI model integration with BYOK (Bring-Your-Own-Key) local storage security.
  - Google OAuth identity linkage support.
