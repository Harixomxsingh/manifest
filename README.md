## 🌟 Highlights & New Features in v1.1.2

- 🔥 **First-Priority Hero Streak Navigation**: Glowing, animated flame badge in the top navigation bar tracking your consecutive daily morning momentum.
- 🟩 **52-Week GitHub-Style Contribution Heatmap**: Full 364-day focus activity grid tracking completed morning rituals and 25-minute deep focus sessions with green dot intensity (Levels 0–4), theme toggles (GitHub Green & Solar Gold), and day inspection.
- 🎆 **Full-Screen Dopamine Celebration**: Multi-stage confetti explosion, harmonic audio victory chime, and visual level-up recognition upon completing your daily morning cadence.
- ⏱️ **25-Minute Deep Focus Pomodoro Timer**: Built-in flow timer that automatically logs focus minutes to your daily contribution squares.
- 🎙️ **Voice & Text Clarity Synthesis**: Spoken or typed manifestation goals with intelligent synthesis.
- 🌦️ **Actionable Atmospheric Intelligence**: Real-time hourly forecast with tailored attire and morning walk guidance.
- 📱 **Cross-Platform Parity**: Full feature parity across both the Web Application and the companion Android / Mobile Expo app (`/mobile`).

## 🧭 The Core Morning Sequence

```
00. Welcome ➔ 01. Identity Anchor ➔ 02. Mindset Reading ➔ 03. Voice Clarity ➔ 04. Atmosphere ➔ 05. Launchpad
```

1. **Phase 00: Executive Welcome** — Radiant morning sunburst, date/time capsule, and the foundational morning manifesto.
2. **Phase 01: Identity Anchor** — Daily identity reminder, stoic reflection passage, and tactile affirmation checklist.
3. **Phase 02: Mindset Reading** — Curated James Clear essay with key takeaways and 1-tap direct article access.
4. **Phase 03: Voice & Text Clarity** — Voice recording or typing to articulate today's single most important focus objective.
5. **Phase 04: Atmosphere** — Real-time weather, daylight window, attire advice, and commute tips.
6. **Phase 05: Launchpad & Focus Grid** — Monolithic summary card, 14-day mini heatmap preview, 1-click summary copy, audio summary narration, and 25m focus sprint launcher.

## 🚀 Quick Start

### 🌐 Web Application (Vite + React)

```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev

# 3. Build for production
npm run build
```
Visit `http://localhost:5173` to experience the app locally, or launch the production version at **[https://harixomxsingh.github.io/manifest/](https://harixomxsingh.github.io/manifest/)**.

---

### 📱 Android & Mobile App (React Native + Expo)

```bash
cd mobile

# 1. Install mobile dependencies
npm install

# 2. Start Expo development server
npx expo start
```
*Open the **Expo Go** app on your Android device to scan the project QR code and run the app natively.*
