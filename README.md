## 🧭 The 4-Phase Core Ritual Path

```
Welcome ➔ 1. Identity & Agency ➔ 2. Mindset Reading ➔ 3. Atmospheric Climate ➔ 4. Day Launchpad
```

1. **Phase 0: Executive Dawn Welcome** — Radiant morning sunburst, live date/time capsule, and the foundational *"Win the Morning, Win the Day"* manifesto.
2. **Phase 1: Identity & Agency** — 365-day rotating identity manifesto, deep stoic reflection passage, and tactile daily affirmation checklist.
3. **Phase 2: Mindset Nutrition** — Daily curated James Clear essay across 9 essential categories (*Continuous Improvement, Habits, Minimalism, Business, Behavioral Psychology, Personal Development, Practical Philosophy, Fundamentals, Creativity*) with 90-day anti-repetition memory and 1-tap direct article access.
4. **Phase 3: Atmospheric Climate** — Automatic GPS geolocation, real-time Open-Meteo temperature feed, 12-hour daylight horizon window, and tailored attire/transit strategy.
5. **Phase 4: Day Launchpad** — Sovereign executive summary slate, synthesized text-to-speech audio dispatch narration, and kickoff to conquer the day.

## ✨ Key Features

- **🎉 Motivational Party Poppers**: Celebratory multi-cannon confetti bursts and harmonic web synthesizer chimes on every step advancement button.
- **📅 Automatic Daily Rotation & Midnight Rollover**: Background monitor auto-refreshes to a brand new article, identity manifesto, and forecast at midnight without any manual intervention.
- **🔀 "Randomize Day" Shuffle**: Test any day's manifestation instantly with the 1-click navigation bar shuffle button.
- **📱 Native Mobile Experience (Expo & React Native)**: Complete mobile application in `/mobile` with native haptics, TTS speech dispatch, and GPS detection.
- **🔒 Sovereign & Zero-Cost**: 100% client-side execution running on zero-cost free-tier APIs.

## 🚀 Quick Start

### 🌐 Web Application (Vite + React)

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

### 📱 Mobile Application (React Native + Expo)

```bash
cd mobile

# Install mobile dependencies
npm install

# Start Expo development server
npx expo start
```
*Scan the generated QR code using the **Expo Go** app on your Android or iOS smartphone.*
